# فريق الذهب (نسخة تجريبية: إشعارات فقط)

## التشغيل
1. ثبّت Python 3.10 أو أحدث.
2. داخل المجلد: `pip install -r requirements.txt`
3. انسخ `.env.example` باسم `.env` واملأ:
   - `ANTHROPIC_API_KEY`: من console.anthropic.com (منفصل عن اشتراك تطبيق Claude، ويُحاسب حسب الاستخدام)
   - `TELEGRAM_TOKEN`: **التوكن الجديد** بعد Revoke من BotFather
   - `ACCOUNT_BALANCE`: رصيد حسابك التجريبي
4. اختبار المنطق بدون إنترنت: `python test_logic.py`
5. التشغيل: `python main.py` (يرسل لك رسالة "اشتغل" على تلكرام)

## كيف يشتغل
- القناص: أخبار وتصريحات ترامب والفيدرالي والخزانة والبيت الأبيض والبنوك المركزية.
- المحقق: أخبار الذهب ومدى مصداقيتها وتفاعل السوق (X اختياري).
- البروفيسور: يشتغل فقط إذا اتفق القناص والمحقق، ويعطي القرار الفني النهائي.
- الإشارة تُرسل فقط إذا اتفق الثلاثة بنفس الاتجاه وثقة كل واحد 65 أو أكثر خلال 30 دقيقة.
- الإعدادات كلها في `config.py`.

## ملاحظات
- السعر من عقود الذهب الآجلة (GC=F) وقد يختلف بضعة دولارات عن XAUUSD عند وسيطك.
- أدخل أوقات أخبار FOMC/CPI/NFP يدوياً في `BLACKOUT_UTC`.
- فحص السبريد والخسارة اليومية والتنفيذ على MT5: مرحلة لاحقة بعد الاختبار.
- لا تنفيذ تلقائي في هذه النسخة، والإشارة ليست ضمان ربح.

## التشغيل المجاني من الجوال (GitHub Actions)
1. أنشئ حساب GitHub ومستودع **Public** جديد (العام = دقائق مجانية غير محدودة، والأسرار تبقى مخفية).
2. ارفع ملفات المشروع (بعد فك الضغط): `*.py` و `requirements.txt` و `.gitignore`.
3. من المتصفح: Add file > Create new file، اكتب الاسم `.github/workflows/gold.yml` والصق محتوى ملف gold.yml.
4. Settings > Secrets and variables > Actions > New repository secret، أضف:
   `ANTHROPIC_API_KEY` و `TELEGRAM_TOKEN` (الجديد) و `TELEGRAM_CHAT_ID`.
   (اختياري: تبويب Variables > `ACCOUNT_BALANCE`)
5. تبويب Actions > gold-agents > Run workflow للتجربة اليدوية، وبعدها يشتغل لحاله كل 5 دقائق (من الأحد للجمعة).

ملاحظات: التأخير بالجدولة ممكن يوصل عدة دقائق. GitHub يوقف الجدولة بعد 60 يوماً بدون نشاط بالمستودع (ادخل وفعّلها من جديد). سجلات Actions عامة بالمستودع العام، لذلك النسخة هذي لا تطبع نص الإشارات.

## سجل النتائج
كل إشارة تُتابع تلقائياً على الشموع: عند ضرب الهدف أو الوقف يوصلك إشعار بالنتيجة والإحصائيات (عدد الصفقات، نسبة النجاح، الصافي بالدولار). الافتراضات: الدخول بسعر الإشارة، وإذا الوقف والهدف بنفس الشمعة يُحسب الوقف، وتُغلق الإشارة بعد 24 ساعة. الإعداد الحالي: رصيد 100$ ولوت ثابت 0.01 (`FIXED_LOT`). لحساب اللوت تلقائياً من نسبة المخاطرة اجعل `FIXED_LOT=0`.
